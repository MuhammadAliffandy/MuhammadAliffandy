### 🚀 About Me

- 🍏 I’m currently an **Apple Developer Academy Scholar**, engineering **iOS Portrait Relighting** powered by **FastViT** running directly on the **Apple Neural Engine (ANE)**.
- 🏥 I’m also working as an **AI/ML Engineer at PukulEnam**, developing **ColonoSense QA** (hybrid clinical LLMs with Llama 3.1) and volumetric brain CT segmentation via **U-Net**.
- 🌱 I’m currently deepening **First-Principles Deep Learning & Transformers** (from-scratch Attention, KV-Cache, and CoreML low-latency optimization).
- 💬 Ask me about **FastViT, CoreML, PyTorch, Swift/SwiftUI, Computer Vision (Face Pose & Relighting), and Medical Image Segmentation**.
- 📫 How to reach me: **aliffandyrealgo@gmail.com**
